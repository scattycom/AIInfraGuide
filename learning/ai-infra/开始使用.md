## 在其他电脑继续

1. 把包含最新本地提交的整个仓库（包括 `.git`）复制到新电脑；或者自行推送该提交后，在新电脑克隆/拉取。仅本地提交不会自动出现在远程或其他电脑。
2. 在 Codex 中打开仓库根目录，输入：

   ```text
   按照 skills/ai-infra-coach/SKILL.md 继续学习，先读取 learning/ai-infra/profile.json、progress.json 和最近会话，从 next_step 接着练习。
   ```

   [AGENTS.md](../../AGENTS.md) 也指向这份技能。无需依赖原电脑用户目录里的个人技能入口；新电脑未配置个人入口时，直接使用上面的文件路径即可。
3. 让教练核对当前电脑的 Python、Linux/WSL 环境。profile 的 GPU、驱动与版本是 2026-09-07 原电脑的验证快照，不代表新电脑配置。当前 Python 基础练习不需要 GPU 或第三方包。
4. 在 Linux/WSL 终端进入新仓库的 `learning/ai-infra/exercises/w01-linux-basics/`，重新创建环境：

   ```bash
   python3 -m venv .venv
   source .venv/bin/activate
   python token_calc.py
   ```

   需要本机 Python 支持 venv；若创建失败，把错误交给教练处理。虚拟环境不随 Git 迁移。脚本按当前工作目录读取 `config.json`，需在上述练习目录运行。当前预期输出为 632、1264、1580、512，各占一行。
